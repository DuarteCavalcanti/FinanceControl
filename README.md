# FinanceControl 
O FinanceControl é um sistema desktop de controle financeiro pessoal desenvolvido com o objetivo de auxiliar os usuários na organização e no acompanhamento de suas finanças. O sistema permitirá registrar receitas e despesas, criar categorias para classificar as movimentações financeiras, definir metas financeiras e visualizar o saldo mensal. 
Dessa forma, busca oferecer uma maneira simples e prática de acompanhar a situação financeira pessoal, facilitando o controle dos gastos e o planejamento do orçamento.

# Funcionalidades

- Registro de receitas: permitir o cadastro de entradas financeiras, informando descrição, valor, data e categoria.
- Registro de despesas: permitir o cadastro de saídas financeiras, informando descrição, valor, data e categoria.
- Gerenciamento de categorias: permitir criar e utilizar categorias para organizar receitas e despesas.
- Definição de metas financeiras: permitir cadastrar metas de economia ou limites de gastos para auxiliar no planejamento financeiro.
- Visualização do saldo mensal: apresentar o total de receitas, o total de despesas e o saldo do mês selecionado.
- Consulta de movimentações: permitir visualizar as receitas e despesas registradas, facilitando o acompanhamento financeiro.
